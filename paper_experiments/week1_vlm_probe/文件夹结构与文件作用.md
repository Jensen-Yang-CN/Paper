## 一、共享框架脚本（val & test 重标/评估都复用）

| 文件 | 作用 |
|---|---|
| `extract_hard_samples.py` | 从数据集抽难样本（低置信度TP/漏检/误检/正常区域），裁剪供 VLM 测试 |
| `test_vlm.py` | VLM 复核探针（含质检提示词 v2/v3 切换，模型经 VLM_MODEL 环境变量切换） |
| `relabel_pipeline.py` | 重标预筛：YOLO 候选 + 千问逐框判定 + 千问全图补漏，生成候选 JSON |
| `relabel_server.py` | 人工确认界面 v2（画布直绘+自动保存+断点续传），通过环境变量切换数据集 |
| `gen_relabeled_labels.py` | 由确认结果生成修正 YOLO 标签（`--mode val/test`） |
| `eval_baseline.py` | 基线评估（mAP + 框级 P/R/F1），`--mode val/test`；数据集路径已指向 Paper |
| `data_cleanup.py` | 孤儿标签清理 + MD5 跨源/泄漏查重 |
| `make_splits.py` | 无泄漏 val/test 分层切分 |
| `build_audit_samples.py`、`analyze_audit.py`、`audit_server.py` | 标注审计的抽样/分析/点选工具 |
