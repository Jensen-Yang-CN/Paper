## 一、数据集与数据文件

| 文件/目录 | 作用 |
|---|---|
| `relabeled_test/`（已搬到 Paper） | 修正 test 集（300 图 + 修正标签 + name_mapping.csv） |
| `test_originals_backup/` | 从 train 移出的 300 张**原图+原始标签**（做"标签修正效应"对比用） |
| `relabel_test_candidates.json` | 预筛候选（YOLO 候选 + 千问判定 + 全图补漏 + auto_keep 标记） |
| `relabel_test_results.json` | 人工确认结果（actions/added） |
| `test_images.txt` | test 切分清单（300 张原始文件名） |
| `final_data.yaml` | **最终数据集划分**（train/val/test 三套，指向 Paper 路径） |
| `hard_set.json` | **Hard Set 定义**：难样本框（按面积/对比度客观属性，不含模型置信度） |

## 二、脚本（第二周专属）

| 文件 | 作用 |
|---|---|
| `relabel_retry.py` | 预筛失败重试（账户欠费修复 + `--fill-scan` 补漏扫） |
| `finalize_test_split.py` | 把 test 图从 train 物理移出 + 生成 data.yaml（已执行过） |
| `verify_v6_on_test.py` | **V6 在 test 上的验证**（mAP + 框级 P/R/F1 + 图像级 P/R/F1），`--original` 对比原始标签 |
| `define_hard_set.py` | 定义 Hard Set（面积/对比度分位） |
| `vlm_baseline_test.py` | **VLM 复核 Baseline 正式化**（qwen3-vl-plus 整图判断，图像级指标） |
| `error_cases.py` | 收集错误案例（漏检/误检/类别冲突）+ 可视化 |
| `h1_confidence_error.py` | **H1 置信度-错误率图** |
