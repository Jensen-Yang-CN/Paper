# 第三周代码说明 —— 方法 V1（YOLO + 置信度路由 + VLM 复核 + 融合）

> 文件：`E:\CodeBase_YangJunJie\Paper\paper_experiments\week3_method\collab_pipeline.py`
> 功能：在重标 test 集上实现并跑通论文核心方法 V1（推理时协同），并对比 YOLO 单独 / 低阈值控制组，输出框级 + 图像级指标、VLM 调用率与延迟。

## 一、整体流程（一条主线）

```
输入每张 test 图
   ↓
YOLO(conf=0.25) 推理 → 检测框 {类别, 框, 置信度}
   ↓
置信度路由(阈值 CONF_HIGH=0.6)
   ├─ 置信度 ≥ 0.6  → 直接接受（信任 YOLO）
   └─ 置信度 < 0.6  → 送 VLM 复核
        ↓
      裁剪(扩边+放大到≥96px) + 尺度信息 + 质检提示词
        ↓
      VLM 返回 {is_defect, category, confidence}
        ↓
      融合规则：is_defect → 保留（类别用 VLM 的做纠错）；否则剔除
   ↓
最终缺陷框 = 高置信直接接受框 + VLM 判定有瑕疵的低置信框
```

## 二、关键函数逐一说明

| 函数 | 作用 |
|---|---|
| `imread_unicode(p)` | 读图。**必须用它**——`cv2.imread` 无法处理含中文的路径（`Paper\实验数据`），改用 `np.fromfile + cv2.imdecode` |
| `load_gt(lbl)` | 读 YOLO 格式标签 → `[(cls, x, y, w, h)]`（归一化坐标） |
| `iou(a, b)` | 两个像素框的 IoU（用于检测↔GT匹配） |
| `crop(img, box)` | 按检测框裁剪并**扩边 30%**；若裁剪太小（<96px）则取以框为中心的最小正方形；返回裁剪图 |
| `vlm_verify(crop_img, api_key, scale)` | 调用 qwen3-vl-plus 判断裁剪图是否有瑕疵。**prompt = scale 尺度提示 + PROMPT**，返回结构化 JSON |
| `match(dets, gt_px, class_mode)` | 检测↔GT 框级匹配，返回 (TP, FP, FN)。`class_mode`：`strict`=同类别才算对（**主指标**）；`agnostic`=命中任一真缺陷位置即对（**辅助指标**） |

## 三、关键参数

| 参数 | 值 | 含义 |
|---|---|---|
| `CONF_HIGH` | 0.60 | 路由阈值：≥此置信度的检测直接接受 |
| `CONF_LOW` | 0.25 | YOLO 推理阈值（低，多抓候选；路由只处理中间区） |
| `CONF0` | 0.40 | "YOLO 单独"基线阈值（对照用） |
| `IOU_THR` | 0.5 | 匹配 IoU 阈值 |
| `CROP_MARGIN` | 0.30 | 裁剪扩边比例 |
| `MIN_CROP` | 96 | 裁剪最小边长 |
| `MODEL`(VLM) | qwen3-vl-plus | 通过环境变量 `VLM_MODEL` 可换 |
| `MODEL_PATH` | `Paper\模型权重\Final_Model_V6_best.pt` | YOLO V6 模型 |

## 四、尺度信息 prompt（本次新增）

低置信度框裁剪后，在 prompt 前注入：
> `[尺度提示] 这是原始图（WxH px）中一块区域放大后的裁剪图，裁剪图本身 cxch px，候选缺陷框占原图面积约 X%。瑕疵可能很小，请据此判断...`

作用：让 VLM 知道"这块区域在原图里有多小/多放大"，避免把微小缺陷误判为"看不清/没有"（H2 的细节实现）。

## 五、评测口径（重要，论文用）

- **框级匹配** IoU=0.5，两种口径都算：**严格**（主指标，标准检测口径）+ **无关**（辅助，"找缺陷位置"）；
- **融合类别**：VLM 判定有瑕疵时，**类别以 VLM 为准**（纠错）；
- **图像级**：图像有无缺陷二分类 F1，作整体参考。
